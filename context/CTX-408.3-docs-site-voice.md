# CTX-408.3: Implementation Context: The Docs Site's Entry Path

> **Spec Reference:** Links to [SPEC-408](../specs/SPEC-408-messaging-for-the-maker-who-is-leveling-up.md)

## 0. What this did not do, deliberately

**Four pages changed out of sixteen.** The docs are well written; they are written for someone who
has already been through the afternoon they describe. The fix for that is not a rewrite — it is an
on-ramp at the entry points, with the existing depth left exactly where it is. `SPEC-408` asked for
*"approachable with depth there as they can read as they learn the app"*, and the depth already
exists.

`why.md`'s datasheet story in particular is kept **whole**. It is the best writing in the repo, and
for a reader who has not hit that afternoon yet it works as a warning rather than a memory — once
something above it explains why they are reading it.

## 1. Feature Definition & Execution Plan

### Phase 1: Start where the reader is
*   [x] `index.mdx` — the hero led with *"One workspace across KiCad and FreeCAD, with an AI layer
        that cites its sources"*. It now starts at the breadboard, and says in the tagline that the
        app works **alongside** KiCad and FreeCAD rather than instead of them.
*   [x] `why.md` — a new opening about the gap between a working breadboard and a correct first
        board, naming the three translations the app does, then handing off to the original story
        under *"The afternoon this was built for"*.
*   [x] `what-it-is.md` — opens by ruling itself out for the reader who wants a schematic drawn,
        then says what it is instead, before the scope boundary.
*   [x] `guides/board-checks.md` — opens with what the reader gets (`power_pin_not_driven` and
        `Net-(U2-THRES)` translated) rather than with which tool runs the check.

### Phase 2: Stop being wrong
*   [x] The docs index announced **`v0.1.1`** as current — three releases stale, the same defect
        `CTX-408.1` found in the README.
*   [x] `install.md` carried a whole note block for `v0.1.0`, ending in
        `xattr -cr /Applications/Hardware\ Agent\ Studio.app` — a repair command naming an
        application that has not existed since `SPEC-405`.
*   [x] `guides/board-checks.md` described the **fallback** as the primary path: *"If you have a
        board open in KiCad, the app finds it automatically."* `BoardAdvisor` prefers the linked
        project's board and only then asks a running KiCad — verified in the source, not assumed.

### Phase 3: Extend the guard
*   [x] The `CTX-408.1` checks now cover every page under `docs/site/src/content/docs`.

## 4. Plan Drift & Architectural Changes

*   **Deviation 1: the docs had the README's disease, and one case was worse.** `index.mdx`
    announced `v0.1.1` and `install.md` told a user to run
    `xattr -cr /Applications/Hardware\ Agent\ Studio.app`. The README's version of that command was
    caught in `CTX-408.1`; this one survived, in a document specifically about installing.

*   **Deviation 2: my own name check walked past it, because the name was shell-escaped.**
    `Hardware\ Agent\ Studio` does not contain the substring `Hardware Agent Studio`. The check
    added one context ago reported the docs clean, and they were not. It now normalises `\ ` before
    searching. **A guard that is silent for the wrong reason is worse than no guard**, and this one
    was silent about the exact defect it was written for, one directory away from where it was
    written.

*   **Deviation 3: a documentation page was wrong about the product, not just old.**
    `guides/board-checks.md` presented "have a board open in KiCad" as the way the PCB tab finds a
    board. `BoardAdvisor` tries the **linked project** first and falls back to a running KiCad — a
    change made when the KiCad-must-be-running requirement was removed, and the guide was never
    updated. Found by reading `BoardAdvisor.tsx` rather than trusting the page, which is the only
    way this class is ever found.

*   **What was left alone, and why that is the harder decision.** Twelve pages are untouched. The
    temptation with a voice brief is to rewrite everything, and the result would be a site that
    reads consistently and says less. The entry path is what decides whether someone stays; the
    reference pages are what they need once they have.
