Copperplane sits next to KiCad and FreeCAD, reads the project you already have, and tells you in
plain language what it finds. It does not draw your schematic, place parts or route your board.

**New here?** [Install it](https://gittielabs.github.io/copperplane/install/), then open the
[example project](https://gittielabs.github.io/copperplane/tutorials/blink-leds/). No API key is
needed to see the checks; the [install page](https://gittielabs.github.io/copperplane/install/)
says exactly what you get without one.

## What's new

- **It speaks before you click.** Open a project and the Overview already lists what needs your
  attention, what the board got right, and where you are in the journey from schematic to order.
  [What it notices](https://gittielabs.github.io/copperplane/guides/what-it-notices/)
- **A mistake neither ERC nor DRC reports.** A symbol whose pin count disagrees with its footprint's
  pad count, such as a two-pin LED symbol on a four-pad RGB footprint, is now flagged. KiCad is
  right not to call it an error; the board still will not work the way you meant.
- **The power path, with the arithmetic shown.** A linear regulator's heat, a supply trace's width
  against the current you gave it, and a power input that can go in backwards.
- **Board houses.** Pick the fab you are ordering from and see which findings change under its
  rules, side by side with KiCad's defaults.
  [Board houses](https://gittielabs.github.io/copperplane/guides/board-houses/)
- **Part search covers KiCad's own libraries.** Every footprint library installed with KiCad is
  searched alongside your own, and a dead datasheet link becomes a search instead of an error.
- **Tell it what you are building**, and it suggests parts against that brief.
- **Reviews are kept.** Leaving a tab no longer throws away a schematic or board review that took
  a real check to produce.
- **Enclosure preview** shows labelled placeholder boxes for parts without a 3D model.
- **macOS installer** opens to a drag-to-Applications window.

## Downloads

| Platform | File | Signed |
| :--- | :--- | :--- |
| macOS, Apple Silicon | `_aarch64.dmg` | Yes, signed and notarized |
| macOS, Intel | `_x64.dmg` | Yes, signed and notarized |
| Windows | `_x64-setup.exe` | Not yet |
| Linux | `.AppImage` or `.deb` | Not yet |

Windows will say the publisher is unknown. Before you run it, you can
[check the file came from this project](https://gittielabs.github.io/copperplane/install/#verify-your-download)
against `SHA256SUMS.txt` and the build's provenance.

## Known limits, stated plainly

- **Every live test against real KiCad and FreeCAD has run on one machine, a Mac.** The automated
  tests run on all three platforms, but nobody here has clicked through the Windows or Linux build.
  If you can, a
  [platform report](https://github.com/GittieLabs/copperplane/issues/new?template=platform_report.yml)
  is worth more to this project than a pull request.
- **In this release, a local model through Ollama is not yet a full replacement for a hosted one.**
  The default local model cannot run the explanations or part lookup. The checks themselves work
  with no model at all. The next release makes Ollama a working way to start, with a model that
  runs the explanations, reviews and chat; part lookup will still need a hosted provider.

The full engineering record for this release, phase by phase, is in the `context/` directories of
the repository.
