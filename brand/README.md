# Copperplane brand assets

Rev A, drawn 2026-08-25. Everything here is generated by `tools/build.py` and
`tools/render.py`, so the geometry cannot drift between formats. Change a colour or a size in the
script and re-run it rather than editing a file by hand.

## The mark

A single copper trace routed into a C, on an 8-unit grid inside a 64x64 board, with 45-degree
miters at every corner and a plated through-hole drilled at each terminal. The app icon inverts it:
the tile is the copper plane and the routed channel exposes the substrate.

## Palette

| Name              | Token         | Hex       | Use                                          | Contrast              |
|-------------------|---------------|-----------|----------------------------------------------|-----------------------|
| Solder mask       | `--green-700` | `#0B5C34` | Rules, pressed states, print                  | 8.09:1 on white       |
| Copperplane green | `--green-600` | `#10743F` | Primary. Mark, links, buttons, focus          | 5.85:1 on white       |
| Signal            | `--green-500` | `#178F4E` | Fills and accents only, never body text       | 4.14:1, large only    |
| Bright            | `--green-300` | `#4FC17E` | Mark and links on dark surfaces               | 8.27:1 on ink         |
| Copper            | `--copper`    | `#C0703A` | Annotation and provenance cues, sparingly     | 3.74:1, large only    |
| Ink               | `--ink`       | `#0A1410` | Dark ground, body text on paper               | 17.35:1 vs paper      |
| Paper             | `--paper`     | `#F4F7F3` | Light ground                                  | —                     |

Signal and Copper both fall under 4.5:1 on white. They are fine for fills, rules, and large display
type, and wrong for body text.

## Type

IBM Plex Sans SemiBold, all caps, tracked +55/1000, converted to outlines. IBM Plex Mono for part
numbers, file paths, and data. Plex is published under the SIL Open Font License 1.1, which permits
commercial use and outlining into a logo. The wordmark files are outlines, so nothing needs to ship
the font to render them.

## Rules

Do:

- Use the `-on-dark` files on dark grounds. The bright green is a different value, not the same
  green lightened by the browser.
- Let the mono lockup inherit `currentColor` for one-colour print, laser engraving, and embedded SVG.
- Keep the mark's mouth pointing right. It reads as a C in one orientation only.
- Keep one trace width of clear space on all four sides.

Don't:

- Redraw the C in another weight or add a second trace. The geometry is the identity.
- Set the wordmark in live text. It is tracked and outlined for a reason.
- Recolour the mark outside the palette, including a gradient.
- Scale the full mark below 24px, or stretch either lockup non-uniformly.
- Add a drop shadow or an outer glow to the tile.

## Rebuilding

```sh
python3 tools/build.py           # SVG sources
python3 tools/render.py          # PNG renders (needs playwright + chromium)
python3 tools/sheet.py           # the identity sheet
python3 tools/dmg_background.py  # the macOS installer background
```

Every path in these scripts resolves from the script's own location, so they run from a fresh
clone anywhere. Until 2026-09-05 they hardcoded the absolute path of the machine they were written
on and this section documented two commands that could not execute; if you are reading an older
checkout, that is why.

`build.py` reads IBM Plex from `@fontsource/ibm-plex-sans` and converts the wordmark to outlines
with fontTools, so a rebuild needs `npm install @fontsource/ibm-plex-sans` plus `fonttools` and
`brotli`.

## App icons

`app-icons/` holds the complete Tauri icon set, ready to drop into
`core/tauri-rust/icons/` (all 16 files). Generated by `tools/appicons.py`.

Assets at or below 48px are rendered from `svg/icon-small.svg`, the small-size drawing, not
downscaled from the full mark. The macOS `.icns` insets the tile to 80.5% of its canvas per
Apple's icon grid; Windows and Linux assets are full bleed.

## The installer window

`tools/dmg_background.py` draws the background for the macOS DMG. Unlike the other tools it needs
neither fontTools nor playwright -- it imports `geometry.py` and writes SVG directly -- so it runs
on a bare Python.

Render it with `rsvg-convert`, not ImageMagick:

```sh
rsvg-convert -w 1320 -h 800 svg/dmg-background.svg -o png/dmg-background.png
cp png/dmg-background.png ../core/tauri-rust/dmg/background.png
```

ImageMagick's SVG renderer honours `fill` and silently ignores `stroke`. The mark and the trace are
stroke-only, so it produces a background with the artwork missing and no error. This is also why
the drawing punches its via holes by overdrawing in the ground colour rather than using an SVG
`mask` the way the other marks do.

The cue is a routed trace, not a generic arrow: it leaves a via under the app icon, breaks at 45
degrees, and ends in an arrowhead under the Applications folder. Both icon positions are held clear
by 74px. It is drawn at 660x400 and rendered at 2x, because Tauri takes a single image rather than
a multi-representation TIFF and the crispness on a retina display comes from Finder scaling down.

The window size and both icon positions live in `core/tauri-rust/tauri.conf.json` under
`bundle.macOS.dmg`. They must match the drawing, and
`services/python-daemon/tests/test_release_checksums.py` fails if they drift.
