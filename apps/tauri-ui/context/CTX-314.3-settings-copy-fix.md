# CTX-314.3: Fix: Settings Community Library Search Copy

> **Spec Reference:** Links to [SPEC-314](../specs/SPEC-314-community-library-discovery.md)

Real, live click-through of `CTX-314.2`'s own shipped Settings screen (2026-08-19) found two real
copy problems in the "Community Library Search" section's description text:

1. It named `SPEC-314` directly to the end user -- a spec ID means nothing to someone using the
   app, and this repo's own convention keeps spec/context references inside code comments, never
   in rendered UI text. No other Settings section leaks an ID this way (verified by grepping every
   `.tsx` file's own JSX text, not just this one).
2. It said "GitHub's lower unauthenticated rate limit" without ever stating what that limit
   actually is, or what adding a token raises it to -- `community_libraries.py`'s own module
   docstring already documents the real numbers (60/hour unauthenticated, 5,000/hour with a token,
   confirmed directly against GitHub's own rate-limit docs during `SPEC-314`'s planning); this fix
   just surfaces the same real numbers to the user instead of leaving them to guess.

## 1. Feature Definition & Execution Plan

*   [x] `apps/tauri-ui/src/components/Settings.tsx`: rewrite the Community Library Search
    description paragraph to drop the spec-id reference and state the real 60/hour vs 5,000/hour
    numbers directly.
