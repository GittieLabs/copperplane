# CTX-205.9: Citation Page Label Clarity

> **Spec Reference:** Links to [SPEC-205](../../../services/python-daemon/specs/SPEC-205-datasheet-design-guidance.md)

## 1. Feature Definition & Execution Plan

Real, direct user feedback on `CTX-205.4`/`.8`'s citation chip: labeling it `p4` assumes the reader
already knows they're looking at a datasheet page reference. Outside that context (a screenshot, a
glance without having opened the datasheet), `p4` reads as an unexplained fragment, not a page
number. Fixed by spelling it out: `Page 4`, unambiguous with no surrounding context required.

### Phase 1: `PartDetail.tsx`
*   [x] Citation chip label changed from `` `p${item.page}` `` to `` `Page ${item.page}` ``.

### Phase 2: tests
*   [x] `PartDetail.test.tsx`: existing citation-chip assertions updated from `'p4'` to `'Page 4'`.

## Files
