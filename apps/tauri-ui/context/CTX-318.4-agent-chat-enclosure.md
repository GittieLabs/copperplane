    keeping the row's own internal layout (and the `result`-conditional `lg:w-96` sidebar sizing)
    completely unchanged, with `AgentChat` as the outer div's second child below it.

## 4. Plan Drift & Architectural Changes

*   **Deviation 1 (real, found while placing the mount, not assumed): `EnclosurePanel`'s existing
    top-level layout is a two-column row, unlike Schematic/PCB's plain single-column stack.**
    *   *Reasoning:* Schematic/PCB (`CTX-318.3`) and Components (`CTX-318.2`) both had an existing
        `flex-col` outer wrapper `AgentChat` could join as a plain sibling. `EnclosurePanel`'s own
        outer wrapper is `lg:flex-row` (sidebar next to the 3D viewer) -- appending `AgentChat`
        directly inside it would have made it a third row-column instead of a footer.
    *   *Impact:* added one new, purely structural outer `flex-col` div around the existing row,
        changing no existing class or behavior inside it. Confirmed via the full test suite (432
        passed) that this didn't alter any existing `EnclosurePanel` test's DOM assertions.
*   **Deviation 2 (real, checked directly rather than assumed): the `App.test.tsx` AgentChat trap
    from `CTX-318.3` did NOT recur here.**
    *   *Reasoning:* `CTX-318.3`'s own Plan Drift predicted this would need re-checking "one level
        further up the tree each time a new area adopts AgentChat" -- worth confirming rather than
        skipping, since `App.test.tsx` renders `EnclosurePanel` unmocked too.
    *   *Impact:* no fix needed. `App.test.tsx`'s `./components/AgentChat` stub added in `CTX-318.3`
        already mocks the module wholesale, not per-consumer -- it covers every component that
        imports `AgentChat`, present and future, not just the two that motivated adding it. The
        prediction in `CTX-318.3` was more cautious than necessary once the fix was actually a
        module-level mock rather than a per-component one; noted here so the next phase (project
        intent/Overview, Phase 5) doesn't re-verify this unnecessarily -- only a *new* test file that
        renders its own `AgentChat`-mounting component unmocked would need the same fix again.
